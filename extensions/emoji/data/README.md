# Emoji data

`emoji.tsv` is generated by [`tools/emojigen`](../../../tools/emojigen/main.go). Do not edit it.

| Source | Version | What it gives |
|---|---|---|
| [emoji-test.txt](https://unicode.org/Public/emoji/16.0/emoji-test.txt) | Emoji 16.0 | The emoji, their order and groups, and skin tone variants |
| [cldr-json](https://github.com/unicode-org/cldr-json/tree/46.0.0) `annotations` and `annotationsDerived`, `en` and `pt` | CLDR 46.0.0 | Names and keywords in English and Portuguese, and the text symbols |

Both are © Unicode, Inc., under the Unicode License v3 in [LICENSE-UNICODE](LICENSE-UNICODE),
which allows redistribution with that notice.

To update, download the files of a newer version as `emoji-test.txt`, `ann-en.json`,
`ann-pt.json`, `der-en.json` and `der-pt.json` into a folder, then:

```bash
go -C tools run ./emojigen -src <folder> -out ../extensions/emoji/data/emoji.tsv
```
