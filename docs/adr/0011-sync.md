# 11. Sync through a user folder, end-to-end encrypted

Status: accepted (2026-10-25)

## Decision

Sync writes records (settings, themes, snippets, quicklinks, AI commands, notes) to a folder the
user picks and syncs with any tool, encrypted with a key derived from a sync passphrase (Argon2id).
Each record carries a logical clock and device ID; merges are last-write-wins per record.
Clipboard history is never synced.

## Consequences

- No server to run or pay for.
- Concurrent edits of the same record keep the latest; acceptable for this data.
