# Changelog

Each version's section is what Althea shows when it offers the update.

## 1.0.0

The first release, for Windows 11. Every feature is free and runs on your computer.

- **Launcher**: one hotkey (Alt+Space, or the Win key alone) opens a search over apps, commands,
  files and more, ranked by what you pick often and recently.
- **Calculator**: math, percentages, units, number bases and currencies by daily rates, in your
  language's format.
- **Clipboard history**: text, links, colors, images and files, encrypted on disk, searchable and
  pinnable. Copies that password managers mark as secret are never kept.
- **Snippets** that paste with placeholders and expand as you type a keyword, and **Quicklinks**
  to pages, files and folders.
- **Window management**: halves, thirds, quarters and your own layouts, from hotkeys.
- **AI**: Quick AI, a chat, and AI Commands on the selected text, with the provider you choose.
- **Translator**: offline, with models downloaded on demand, or through an online provider.
- **Floating Notes**: Markdown notes in a small window that stays on top, encrypted on disk.
- **Themes**: TOML themes you can edit while Althea runs, and a theme editor with a live preview.
- **Sync**: settings, themes, snippets, quicklinks, AI Commands and notes through a folder you
  sync, end-to-end encrypted with a passphrase.
- **Extensions**: Script Commands in any language, and Go extensions with the same API as the
  built-in ones.
- **Updates**: signed, downloaded as small deltas, and checked only if you opt in.
- English and Brazilian Portuguese.
